# AnchorOfMobius
We made a deep sea exploration game for a hackathon where you, pilot, a bathysphere down 4000m to fix the roots holding your floating island in place. Each zone has these mini challenges like memory matching, reaction clicking, word scrambles, and as you go deeper the vibe gets progressively more unhinged. the big twist is the roots aren't roots, your island is literally just sitting on top of a sleeping god and you accidentally woke it up. ends with a choice between sacrificing yourself to put it back to sleep or just opening the hatch and letting it in. built the whole thing in a single html file by compressing code from multiple files.
